# Local thesis data

Only this guide and the source-directory placeholder are tracked. Store public
captures, prepared corpora and immutable evaluation runs here. Keep approved,
anonymized student-office intake under `data/private/`, outside the retrieval index.
No real correspondence is supplied by this repository.

See `docs/organization.md` for the local corpus locations. `data/archive/` contains
local recovery copies and historical artifacts; it must not be added to Git.
Keep frozen corpus metadata unchanged because snapshots and review hashes bind to it.
Source configuration lives in `config/`; refreshes write new directories.
